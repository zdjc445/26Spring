# 软工二期末突击资料

本目录面向零基础期末突击复习，全部资料已生成 `md`、`tex`、`pdf` 三种版本。

使用顺序：

1. 先读 `00-零基础期末总复习资料.pdf`，背十类题型模板。
2. 再读 `软工二期末名词解释.pdf`，补齐名词解释、简答题和边角概念。
3. 做 `模拟卷/软工二最简综合卷与补充模拟卷.pdf`，先用最简综合卷压缩复习，再用补充模拟卷补旧题题型。
4. 再做 `模拟卷/` 下 8 套系统场景模拟卷，每套先做 A 卷题目，再对照 B 详解。
5. 错题回到 `软工二课程整理/` 中对应分卷补细节。

模拟卷覆盖方向：

- `软工二最简综合卷与补充模拟卷.pdf`
- `模拟卷01-校园卡自助系统题目与详解.pdf`
- `模拟卷02-进销存采购补货系统题目与详解.pdf`

- `模拟卷08-实验室设备预约报修系统题目与详解.pdf`
