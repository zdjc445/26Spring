# 02 渐进符号定义与证明

## 题目原文

$O$、$\Omega$、$\Theta$ 的定义和相关函数证明

## 考查类型

概念题和证明题。

## 三个定义

设 $f(n)$ 和 $g(n)$ 是非负函数。

$f(n) = O(g(n))$ 表示 $f$ 被 $g$ 渐进上界控制：

```text
存在正常数 c 和 n₀，使得对所有 n ≥ n₀，有 0 ≤ f(n) ≤ c g(n)
```

$f(n) = \Omega(g(n))$ 表示 $f$ 被 $g$ 渐进下界控制：

```text
存在正常数 c 和 n₀，使得对所有 n ≥ n₀，有 0 ≤ c g(n) ≤ f(n)
```

$f(n) = \Theta(g(n))$ 表示二者同阶：

```text
存在正常数 c₁, c₂ 和 n₀，使得对所有 n ≥ n₀，有 0 ≤ c₁ g(n) ≤ f(n) ≤ c₂ g(n)
```

等价地：

```text
f(n) = Θ(g(n)) 当且仅当 f(n) = O(g(n)) 且 f(n) = Ω(g(n))
```

## 证明方法

证明 $O$：找到一个常数 $c$，让 $f(n) \le c g(n)$ 在足够大的 $n$ 上成立。

证明 $\Omega$：找到一个常数 $c$，让 $f(n) \ge c g(n)$ 在足够大的 $n$ 上成立。

证明 $\Theta$：同时证明上界和下界。

## 示例

证明 $3n^2 + 5n + 7 = O(n^2)$。

当 $n \ge 1$ 时：

```text
3n² + 5n + 7 ≤ 3n² + 5n² + 7n² = 15n²
```

取 $c = 15, n_0 = 1$，定义满足，因此结论成立。

证明 $3n^2 + 5n + 7 = \Omega(n^2)$。

当 $n \ge 1$ 时：

```text
3n² + 5n + 7 ≥ 3n²
```

取 $c = 3, n_0 = 1$，定义满足，因此结论成立。

由上界和下界同时成立，得到：

```text
3n² + 5n + 7 = Θ(n²)
```

## 常用性质

传递性：

```text
f = O(g), g = O(h) ⇒ f = O(h)
```

同阶对称性：

```text
f = Θ(g) ⇒ g = Θ(f)
```

多项式主项支配：

```text
a_d nᵈ + ... + a₁ n + a₀ = Θ(nᵈ)
```

这里要求最高次项系数 $a_d > 0$。

## 例题

### 例题 1

题目：用定义证明：

```text
5n³ + 2n² + 7 = O(n³)
```

解答：

当 $n \ge 1$ 时：

```text
5n³ + 2n² + 7 ≤ 5n³ + 2n³ + 7n³ = 14n³
```

取：

```text
c = 14
n₀ = 1
```

由 $O$ 的定义，结论成立。

### 例题 2

题目：用定义证明：

```text
5n³ + 2n² + 7 = Θ(n³)
```

解答：

上界由例题 1 得到：

```text
5n³ + 2n² + 7 ≤ 14n³
```

下界为：

```text
5n³ + 2n² + 7 ≥ 5n³
```

取：

```text
c₁ = 5
c₂ = 14
n₀ = 1
```

满足：

```text
c₁ n³ ≤ 5n³ + 2n² + 7 ≤ c₂ n³
```

所以：

```text
5n³ + 2n² + 7 = Θ(n³)
```

## 常见误区

不要只代入几个数值说明渐进关系。渐进证明必须给出常数和阈值。

不要把 $O$ 当成等号意义上的相等。$O$ 表示上界关系，不表示精确增长。
