# 12 动态规划

## 题目原文

动态规划的思想和特点，针对经典问题能写出子问题的递归式，描述算法思想和伪代码：最长公共子序列相关问题、抽牌拿取最大值问题、回文判断/分割相关问题。

## 考查类型

概念题和算法设计题。

## 动态规划思想

动态规划用于具有以下性质的问题：

```text
最优子结构
重叠子问题
```

做法是先定义状态，再写状态转移，最后确定计算顺序。

答题四步：

1. 定义 `dp` 状态含义。
2. 写初始条件。
3. 写状态转移方程。
4. 说明遍历顺序和最终答案。

## 最长公共子序列

给定字符串 `X[1..m]` 和 `Y[1..n]`，令：

```text
dp[i][j] = X[1..i] 和 Y[1..j] 的最长公共子序列长度
```

初始条件：

```text
dp[0][j] = 0
dp[i][0] = 0
```

状态转移：

```text
if X[i] == Y[j]:
    dp[i][j] = dp[i-1][j-1] + 1
else:
    dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

答案：

```text
dp[m][n]
```

时间复杂度：

```text
O(mn)
```

空间复杂度：

```text
O(mn)
```

若只要求长度，可以滚动数组优化为 $O(n)$ 空间。

## 抽牌拿取最大值问题

PDF 未给出完整题面。以下小节只分析本文件采用的练习模型：一排牌，每次只能从左端或右端取一张，两人都采用最优策略，求先手能取得的最大收益或最大分差。课堂题面不同，则需要按课堂题面重写该小节。

定义：

```text
dp[i][j] = 当前行动者面对区间 cards[i..j] 时，相对对手最多领先多少分
```

状态转移：

```text
dp[i][j] = max(
    cards[i] - dp[i+1][j],
    cards[j] - dp[i][j-1]
)
```

含义：

当前行动者若取左端 `cards[i]`，接下来对手面对 `[i+1..j]`，对手相对当前行动者的领先为 `dp[i+1][j]`，所以当前行动者净领先为 `cards[i] - dp[i+1][j]`。

初始条件：

```text
dp[i][i] = cards[i]
```

计算顺序：

```text
区间长度从 1 到 n
```

答案：

```text
dp[0][n-1]
```

若需要先手最大总分，可结合总分 $S$ 得到：

```text
first = (S + dp[0][n-1]) / 2
```

## 回文判断

给定字符串 `s[0..n-1]`，令：

```text
pal[i][j] = s[i..j] 是否为回文串
```

初始和转移：

```text
pal[i][i] = true
pal[i][i+1] = (s[i] == s[i+1])

if s[i] == s[j] and pal[i+1][j-1]:
    pal[i][j] = true
else:
    pal[i][j] = false
```

计算顺序：

```text
按区间长度从短到长
```

## 回文分割

目标：将字符串切成若干回文子串，求最少切割次数。

先用上面的 `pal[i][j]` 预处理任意区间是否回文。

令：

```text
cut[i] = s[0..i] 的最少切割次数
```

转移：

```text
if pal[0][i]:
    cut[i] = 0
else:
    cut[i] = min(cut[j] + 1) for 0 ≤ j < i and pal[j+1][i]
```

时间复杂度：

```text
O(n²)
```

## 例题

### 例题 1

题目：求字符串 $X = ABCBDAB$ 和 $Y = BDCABA$ 的最长公共子序列长度。

解答：

令：

```text
dp[i][j] = X[1..i] 和 Y[1..j] 的最长公共子序列长度
```

按转移方程填表后得到：

```text
dp[7][6] = 4
```

因此最长公共子序列长度为 `4`。一个长度为 4 的公共子序列为：

```text
BCBA
```

### 例题 2

题目：一排牌为：

```text
[3, 9, 1, 2]
```

每次只能从左端或右端取牌，两人都采用最优策略。求先手最终得分。

解答：

沿用上文定义：

```text
dp[i][j] = 当前行动者面对 cards[i..j] 时，相对对手最多领先多少分
```

单元素区间：

```text
dp[0][0] = 3
dp[1][1] = 9
dp[2][2] = 1
dp[3][3] = 2
```

长度为 2：

```text
dp[0][1] = max(3 - 9, 9 - 3) = 6
dp[1][2] = max(9 - 1, 1 - 9) = 8
dp[2][3] = max(1 - 2, 2 - 1) = 1
```

长度为 3：

```text
dp[0][2] = max(3 - 8, 1 - 6) = -5
dp[1][3] = max(9 - 1, 2 - 8) = 8
```

长度为 4：

```text
dp[0][3] = max(3 - 8, 2 - (-5)) = 7
```

总分为：

```text
3 + 9 + 1 + 2 = 15
```

先手得分为：

```text
(15 + 7) / 2 = 11
```

### 例题 3

题目：对字符串 `aab` 求最少回文分割次数。

解答：

回文子串包括：

```text
a
a
b
aa
```

最优分割为：

```text
aa | b
```

切割次数为：

```text
1
```

用 `cut` 表示：

```text
cut[0] = 0        a
cut[1] = 0        aa
cut[2] = cut[1] + 1 = 1
```

所以答案为 `1`。

## 常见误区

动态规划不是只写递归式。完整答案还要说明状态含义、边界条件、计算顺序和最终答案。

区间动态规划要按区间长度递增计算，避免使用尚未计算出的状态。

最长公共子序列不是最长公共子串。子序列允许不连续，子串必须连续。
