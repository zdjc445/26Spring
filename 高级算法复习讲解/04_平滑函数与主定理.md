# 04 平滑函数与主定理

## 题目原文

了解平滑函数性质，应用主定理求解一般式：

```text
T(n) = bT(n/c) + f(n)
```

## 考查类型

概念题和递推分析题。

## 递推含义

递推式：

```text
T(n) = bT(n/c) + f(n)
```

表示一个规模为 $n$ 的问题被分成 `b` 个规模为 `n/c` 的子问题，合并或额外处理代价为 $f(n)$。

其中通常有：

```text
b ≥ 1
c > 1
```

关键比较对象是：

```text
n^{log_c b}
```

它表示递归树中叶子层的总规模量级。

## 主定理三种情形

令：

```text
α = log_c b
```

第一种：$f(n)$ 比 $n^\alpha$ 多项式意义下更小。

```text
f(n) = O(n^{α - ε})
```

其中 $\varepsilon > 0$，则：

```text
T(n) = Θ(n^α)
```

第二种：$f(n)$ 与 $n^\alpha$ 同阶。

```text
f(n) = Θ(n^α)
```

则：

```text
T(n) = Θ(n^α log n)
```

第三种：$f(n)$ 比 $n^\alpha$ 多项式意义下更大，并满足正则条件。

```text
f(n) = Ω(n^{α + ε})
```

且存在常数 $q < 1$，使得：

```text
b f(n/c) ≤ q f(n)
```

则：

```text
T(n) = Θ(f(n))
```

## 平滑函数的作用

在主定理相关证明中，平滑性质用于处理 $n$ 不是 $c$ 的整数幂时的情况，并保证函数在按常数比例缩放时增长不发生剧烈跳变。

常见的平滑函数包括：

```text
nᵈ
nᵈ logᵏ n
```

其中 `d` 和 `k` 是常数，且函数在讨论区间内非负。

这些函数满足按常数倍缩放时仍保持同一量级：

```text
f(cn) = Θ(f(n))
```

## 例子

归并排序：

```text
T(n) = 2T(n/2) + n
```

这里：

```text
b = 2
c = 2
α = log₂ 2 = 1
f(n) = n = Θ(n¹)
```

属于第二种情形：

```text
T(n) = Θ(n log n)
```

二分查找：

```text
T(n) = T(n/2) + 1
```

这里：

```text
b = 1
c = 2
α = log₂ 1 = 0
f(n) = 1 = Θ(n⁰)
```

属于第二种情形：

```text
T(n) = Θ(log n)
```

## 答题模板

1. 写出 `b`、$c$、$f(n)$。
2. 计算 $\alpha = \log_c b$。
3. 比较 $f(n)$ 和 $n^\alpha$。
4. 判断主定理情形。
5. 写出 $T(n)$ 的 $\Theta$ 结果。

## 例题

### 例题 1

题目：求解：

```text
T(n) = 3T(n/2) + n
```

解答：

这里：

```text
b = 3
c = 2
α = log₂ 3
f(n) = n
```

因为：

```text
n = O(n^{log₂ 3 - ε})
```

可取 $\varepsilon = \log_2 3 - 1$。因此属于主定理第一种情形：

```text
T(n) = Θ(n^{log₂ 3})
```

### 例题 2

题目：求解：

```text
T(n) = 4T(n/2) + n²
```

解答：

这里：

```text
b = 4
c = 2
α = log₂ 4 = 2
f(n) = n²
```

因为：

```text
f(n) = Θ(n^α)
```

属于主定理第二种情形：

```text
T(n) = Θ(n² log n)
```

### 例题 3

题目：求解：

```text
T(n) = 2T(n/2) + n²
```

解答：

这里：

```text
b = 2
c = 2
α = log₂ 2 = 1
f(n) = n²
```

$f(n)$ 多项式意义下大于 $n^\alpha$。检查正则条件：

```text
2f(n/2) = 2(n/2)² = n²/2 ≤ (1/2)f(n)
```

取 $q = 1/2$，正则条件成立。属于主定理第三种情形：

```text
T(n) = Θ(n²)
```

## 常见误区

第三种情形不能只比较大小，还要检查正则条件。

第二种情形要求同阶。若出现 $n^\alpha \log^k n$，需要按课堂给出的扩展主定理处理。
