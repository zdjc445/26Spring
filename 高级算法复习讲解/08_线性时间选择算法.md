# 08 线性时间选择算法

## 题目原文

线性时间选择算法的实现和应用

## 考查类型

算法设计题和复杂度分析题。

## 问题定义

选择问题是：给定 $n$ 个元素和整数 `k`，找出第 `k` 小的元素。

特殊情况：

```text
k = 1        找最小值
k = n        找最大值
k = (n+1)/2  找中位数
```

## 随机选择算法思想

随机选择与快速排序的划分类似：

1. 选一个划分基准。
2. 按基准把数组分成小于、等于、大于三部分。
3. 根据 `k` 所在范围，只递归进入一边。

平均时间复杂度：

```text
O(n)
```

最坏时间复杂度：

```text
O(n²)
```

## 确定性线性时间选择算法

也称中位数的中位数方法。

步骤：

1. 将 $n$ 个元素每 5 个分成一组。
2. 对每组内部排序，取每组中位数。
3. 递归地从这些中位数中选出中位数，作为划分基准。
4. 用该基准对原数组划分。
5. 根据 `k` 的位置，只递归进入一边。

## 为什么是线性时间

每组 5 个元素。取所有组的中位数后，再取这些中位数的中位数作为划分基准。

至少一半的组中位数不小于该基准。每个这样的组中，至少有 3 个元素不小于该组中位数，因此也不小于该基准。取整项只影响常数，不影响线性时间结论。

由此可保证每次递归至少排除常数比例的元素。

递推可写为：

```text
T(n) ≤ T(n/5) + T(7n/10) + O(n)
```

解得：

```text
T(n) = O(n)
```

## 应用

找中位数：使用 $Select(A, \lceil n/2 \rceil)$。

找第 $k$ 小：

```text
Select(A, k)
```

找前 `k` 小元素：

先用选择算法找到第 `k` 小的元素，再按该元素划分数组。

找分位点：

递归使用选择算法找多个秩位置的元素。

## 伪代码框架

```text
Select(A, k):
    if |A| is small:
        sort A
        return A[k]

    split A into groups of 5
    M = medians of all groups
    p = Select(M, ⌈|M| / 2⌉)

    partition A into L, E, G by p

    if k ≤ |L|:
        return Select(L, k)
    else if k ≤ |L| + |E|:
        return p
    else:
        return Select(G, k - |L| - |E|)
```

## 例题

### 例题 1

题目：在数组中找第 `5` 小元素：

```text
A = [9, 1, 7, 3, 8, 2, 6, 5, 4]
```

解答：

按升序排列用于核对结果：

```text
[1, 2, 3, 4, 5, 6, 7, 8, 9]
```

第 `5` 小元素为：

```text
5
```

选择算法不需要完整排序。一次以 `5` 为基准划分：

```text
L = [1, 3, 2, 4]
E = [5]
G = [9, 7, 8, 6]
```

因为：

```text
|L| = 4
|L| + |E| = 5
```

第 `5` 小元素正好落在 $E$ 中，答案是 `5`。

### 例题 2

题目：对下面数组使用中位数的中位数方法选取划分基准，并求第 `8` 小元素。

```text
[12, 5, 7, 1, 9, 3, 14, 6, 10, 2, 8, 15, 4, 13, 11]
```

解答：

每 5 个一组：

```text
[12, 5, 7, 1, 9]       中位数 7
[3, 14, 6, 10, 2]      中位数 6
[8, 15, 4, 13, 11]     中位数 11
```

中位数组为：

```text
[7, 6, 11]
```

其中位数是 `7`，取 `7` 为划分基准。

划分后：

```text
L = [5, 1, 3, 6, 2, 4]
E = [7]
G = [12, 9, 14, 10, 8, 15, 13, 11]
```

因为：

```text
|L| = 6
|L| + |E| = 7
```

第 `8` 小元素在 `G` 中，并且是 `G` 的第 `1` 小元素。`G` 的最小值为：

```text
8
```

因此原数组第 `8` 小元素是 `8`。

## 常见误区

线性时间选择算法不需要完整排序。完整排序是 $O(n \log n)$，选择算法只递归处理一边。

每组大小取 5 是为了保证递推能收敛到线性时间。组大小不是随意选择的。
