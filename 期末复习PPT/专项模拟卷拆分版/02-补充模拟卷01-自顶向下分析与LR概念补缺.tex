\subsection*{一、递归下降、回溯与左公因子答案}
\addcontentsline{toc}{subsection}{一、递归下降、回溯与左公因子答案}

原文法：

\begin{quote}
\footnotesize
\begin{verbatim}
S -> a A | a B
\end{verbatim}
\end{quote}

两条 \texttt{S} 的产生式右部都以 \texttt{a} 开头。递归下降分析看到输入第一个符号 \texttt{a} 时，不能只根据这一个符号判断应该选择 \texttt{S -> a A} 还是 \texttt{S -> a B}，因此可能先选错再回溯。

提取左公因子：

\begin{quote}
\footnotesize
\begin{verbatim}
S  -> a S'
S' -> A | B
A  -> c
B  -> d
\end{verbatim}
\end{quote}

也可以直接写成：

\begin{quote}
\footnotesize
\begin{verbatim}
S  -> a S'
S' -> c | d
\end{verbatim}
\end{quote}

判断：

\begin{quote}
\footnotesize
\begin{verbatim}
FIRST(c) = { c }
FIRST(d) = { d }
\end{verbatim}
\end{quote}

两条 \texttt{S'} 规则右部的 FIRST 集不相交，因此提取左公因子后可以构造 LL(1) 预测分析表。

\subsection*{二、二义性文法与预测分析表答案}
\addcontentsline{toc}{subsection}{二、二义性文法与预测分析表答案}

该文法：

\begin{quote}
\footnotesize
\begin{verbatim}
E -> E + E | E * E | id
\end{verbatim}
\end{quote}

不适合直接构造 LL(1) 预测分析表，原因：

\begin{quote}
\footnotesize
\begin{verbatim}
1. 有直接左递归：E -> E + E 和 E -> E * E。
2. 没有体现 + 和 * 的优先级与结合性，表达式可能有多棵语法树。
\end{verbatim}
\end{quote}

例如：

\begin{quote}
\footnotesize
\begin{verbatim}
id + id * id
\end{verbatim}
\end{quote}

可能先结合 \texttt{+}，也可能先结合 \texttt{*}。通常需要：

\begin{quote}
\footnotesize
\begin{verbatim}
1. 改写文法，消除二义性。
2. 消除左递归。
3. 必要时提取左公因子。
4. 再计算 FIRST、FOLLOW 并构造预测分析表。
\end{verbatim}
\end{quote}

\subsection*{三、句柄与归约序列答案}
\addcontentsline{toc}{subsection}{三、句柄与归约序列答案}

输入：

\begin{quote}
\footnotesize
\begin{verbatim}
a b
\end{verbatim}
\end{quote}

自底向上归约：

\begin{quote}
\footnotesize
\begin{verbatim}
a b
=> A b
=> A B
=> S
\end{verbatim}
\end{quote}

每一步都是把某个产生式右部归约为左部：

\begin{quote}
\footnotesize
\begin{verbatim}
a => A
b => B
A B => S
\end{verbatim}
\end{quote}

自底向上分析的归约序列等价于某个最右推导的逆过程。

对应最右推导：

\begin{quote}
\footnotesize
\begin{verbatim}
S => A B => A b => a b
\end{verbatim}
\end{quote}

\subsection*{四、规约-规约冲突答案}
\addcontentsline{toc}{subsection}{四、规约-规约冲突答案}

状态中有两个完成项：

\begin{quote}
\footnotesize
\begin{verbatim}
A -> id .
B -> id .
\end{verbatim}
\end{quote}

在 LR(0) 中，完成项会在所有终结符上放置规约动作，因此同一状态可能同时要求：

\begin{quote}
\footnotesize
\begin{verbatim}
reduce A -> id
reduce B -> id
\end{verbatim}
\end{quote}

这就是规约-规约冲突。

若：

\begin{quote}
\footnotesize
\begin{verbatim}
FOLLOW(A) = { ; }
FOLLOW(B) = { ) }
\end{verbatim}
\end{quote}

SLR 只在 FOLLOW 集对应的终结符上填规约：

\begin{quote}
\footnotesize
\begin{verbatim}
ACTION[状态, ;] = r(A -> id)
ACTION[状态, )] = r(B -> id)
\end{verbatim}
\end{quote}

如果 \texttt{FOLLOW(A)} 和 \texttt{FOLLOW(B)} 有公共符号，那么公共符号对应的 ACTION 表项仍然会同时出现两个规约动作，冲突仍然存在。

\subsection*{五、内核项、非内核项与 SLR 弱点答案}
\addcontentsline{toc}{subsection}{五、内核项、非内核项与 SLR 弱点答案}

内核项：

\begin{quote}
\footnotesize
\begin{verbatim}
1. 初始项 S' -> . S。
2. 所有点不在产生式最左端的 LR(0) 项。
\end{verbatim}
\end{quote}

非内核项：

\begin{quote}
\footnotesize
\begin{verbatim}
除了 S' -> . S 之外，点在产生式最左端的项。
\end{verbatim}
\end{quote}

SLR 比 LR(0) 强：

\begin{quote}
\footnotesize
\begin{verbatim}
LR(0) 对完成项不看输入符号，容易在所有终结符上放置规约。
SLR 使用 FOLLOW 集限制规约，只在 FOLLOW(A) 上对 A -> alpha . 规约。
\end{verbatim}
\end{quote}

SLR 的弱点：

\begin{quote}
\footnotesize
\begin{verbatim}
FOLLOW 集只和非终结符有关，不区分具体 LR 状态中的上下文。
FOLLOW 集过大时，仍可能在不该规约的位置放置规约动作。
因此有些冲突需要 LR(1) 或 LALR(1) 才能处理。
\end{verbatim}
\end{quote}
