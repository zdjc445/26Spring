\subsection*{二、LL(1) 答案}
\addcontentsline{toc}{subsection}{二、LL(1) 答案}

消除直接左递归：

\begin{quote}
\footnotesize
\begin{verbatim}
E  -> T E'
E' -> + T E' | epsilon
T  -> F T'
T' -> * F T' | epsilon
F  -> ( E ) | id
\end{verbatim}
\end{quote}

FIRST：

\begin{quote}
\footnotesize
\begin{verbatim}
FIRST(E)  = { (, id }
FIRST(E') = { +, epsilon }
FIRST(T)  = { (, id }
FIRST(T') = { *, epsilon }
FIRST(F)  = { (, id }
\end{verbatim}
\end{quote}

FOLLOW：

\begin{quote}
\footnotesize
\begin{verbatim}
FOLLOW(E)  = { ), $ }
FOLLOW(E') = { ), $ }
FOLLOW(T)  = { +, ), $ }
FOLLOW(T') = { +, ), $ }
FOLLOW(F)  = { *, +, ), $ }
\end{verbatim}
\end{quote}

预测分析表：

\begin{quote}
\footnotesize
\begin{verbatim}
M[E,  ( ] = E -> T E'
M[E, id ] = E -> T E'

M[E', + ] = E' -> + T E'
M[E', ) ] = E' -> epsilon
M[E', $ ] = E' -> epsilon

M[T,  ( ] = T -> F T'
M[T, id ] = T -> F T'

M[T', * ] = T' -> * F T'
M[T', + ] = T' -> epsilon
M[T', ) ] = T' -> epsilon
M[T', $ ] = T' -> epsilon

M[F,  ( ] = F -> ( E )
M[F, id ] = F -> id
\end{verbatim}
\end{quote}


结论：

\begin{quote}
\footnotesize
\begin{verbatim}
预测分析表没有多重入口，因此消除左递归后的文法是 LL(1)。
\end{verbatim}
\end{quote}

预测分析表（表格形式）：
\begin{center}\footnotesize
\begin{tabular}{lll}
非终结符 & 输入符号 & 产生式\\
E & ( & E -> T E'\\
E & id & E -> T E'\\
E' & + & E' -> + T E'\\
E' & ) & E' -> epsilon\\
E' & \$ & E' -> epsilon\\
T & ( & T -> F T'\\
T & id & T -> F T'\\
T' & * & T' -> * F T'\\
T' & + & T' -> epsilon\\
T' & ) & T' -> epsilon\\
T' & \$ & T' -> epsilon\\
F & ( & F -> ( E )\\
F & id & F -> id
\end{tabular}
\end{center}


\subsection*{三、LR(0)/SLR 答案}
\addcontentsline{toc}{subsection}{三、LR(0)/SLR 答案}

规范 LR(0) 项集族：

\begin{quote}
\footnotesize
\begin{verbatim}
I0:
S' -> . S
S  -> . C C
C  -> . c C
C  -> . d

I1:
S' -> S .

I2:
S -> C . C
C -> . c C
C -> . d

I3:
C -> c . C
C -> . c C
C -> . d

I4:
C -> d .

I5:
S -> C C .

I6:
C -> c C .
\end{verbatim}
\end{quote}

GOTO：

\begin{quote}
\footnotesize
\begin{verbatim}
GOTO(I0, S) = I1
GOTO(I0, C) = I2
GOTO(I0, c) = I3
GOTO(I0, d) = I4

GOTO(I2, C) = I5
GOTO(I2, c) = I3
GOTO(I2, d) = I4

GOTO(I3, C) = I6
GOTO(I3, c) = I3
GOTO(I3, d) = I4
\end{verbatim}
\end{quote}

FOLLOW：

\begin{quote}
\footnotesize
\begin{verbatim}
FOLLOW(S) = { $ }
FOLLOW(C) = { c, d, $ }
\end{verbatim}
\end{quote}

\begin{quote}
\footnotesize
\begin{verbatim}
ACTION[0,c] = s3
ACTION[0,d] = s4
GOTO[0,S] = 1

ACTION[1,$] = acc

ACTION[2,c] = s3
ACTION[2,d] = s4
GOTO[2,C] = 5

ACTION[3,c] = s3
ACTION[3,d] = s4
GOTO[3,C] = 6

\subsection*{四、语义分析答案}
\addcontentsline{toc}{subsection}{四、语义分析答案}

L 属性 SDD：

\begin{quote}
\footnotesize
\begin{verbatim}
D -> T L
  L.in = T.type

T -> int
  T.type = int

T -> float
  T.type = float

L -> id L'
  addType(id.name, L.in)
  L'.in = L.in

L' -> , id L'1
  addType(id.name, L'.in)
  L'1.in = L'.in

L' -> epsilon
  不执行动作
\end{verbatim}
\end{quote}

这是 L 属性的原因：

\begin{quote}
\footnotesize
\begin{verbatim}
L.in 来自左侧的 T.type。
L'.in 来自父结点 L 或 L'。
继承属性只依赖父结点或左侧兄弟结点，不依赖右侧兄弟结点。
\end{verbatim}
\end{quote}

S 属性 SDD：

\begin{quote}
\footnotesize
\begin{verbatim}
E -> E1 + T
  E.code = E1.code || T.code || "+"

E -> T
  E.code = T.code

T -> num
  T.code = num.lexeme
\end{verbatim}
\end{quote}

计算：

\begin{quote}
\footnotesize
\begin{verbatim}
3 + 4 + 5 按左结合为 ((3 + 4) + 5)

3 + 4 的 code = 3 4 +
(3 + 4) + 5 的 code = 3 4 + 5 +

最终 E.code = 3 4 + 5 +
\end{verbatim}
\end{quote}

\end{quote}
