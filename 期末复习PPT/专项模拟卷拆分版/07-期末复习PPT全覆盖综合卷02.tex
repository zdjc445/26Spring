\subsection*{一、词法分析与 LL(1) 分析解析}
\addcontentsline{toc}{subsection}{一、词法分析与 LL(1) 分析解析}


\paragraph*{（一）词法分析解析}

采用如下 Thompson NFA，起始状态为 \texttt{q0}，接受状态为 \texttt{q9}：

\begin{quote}
\footnotesize
\begin{verbatim}
q0 --epsilon--> q1
q0 --epsilon--> q7

q1 --epsilon--> q2
q1 --epsilon--> q4
q2 --a-------> q3
q4 --b-------> q5
q3 --epsilon--> q6
q5 --epsilon--> q6

q6 --epsilon--> q1
q6 --epsilon--> q7

q7 --epsilon--> q8
q8 --a-------> q9
\end{verbatim}
\end{quote}

含义：\texttt{q1} 到 \texttt{q6} 表示 \texttt{a|b}，\texttt{q0、q7} 实现 Kleene 星，\texttt{q8 --a--> q9} 表示末尾必须再读一个 \texttt{a}。

初始 epsilon-closure：

\begin{quote}
\footnotesize
\begin{verbatim}
D0 = epsilon-closure({q0})
   = {q0,q1,q2,q4,q7,q8}
\end{verbatim}
\end{quote}

子集构造：

\begin{quote}
\footnotesize
\begin{verbatim}
D0 --a--> epsilon-closure({q3,q9})
         = {q1,q2,q3,q4,q6,q7,q8,q9}
         = D1

D0 --b--> epsilon-closure({q5})
         = {q1,q2,q4,q5,q6,q7,q8}
         = D2

D1 --a--> D1
D1 --b--> D2
D2 --a--> D1
D2 --b--> D2
\end{verbatim}
\end{quote}

DFA 状态表：

\begin{quote}
\footnotesize
\begin{verbatim}
状态  NFA 状态集合                         a   b   接受
D0    {q0,q1,q2,q4,q7,q8}                 D1  D2  否
D1    {q1,q2,q3,q4,q6,q7,q8,q9}           D1  D2  是
D2    {q1,q2,q4,q5,q6,q7,q8}              D1  D2  否
\end{verbatim}
\end{quote}

最小化：

\begin{quote}
\footnotesize
\begin{verbatim}
初始划分：{D1}、{D0,D2}
D0 和 D2 在 a 上都到 D1，在 b 上都到 {D0,D2}，因此等价。

令 N={D0,D2}，F={D1}。

状态  a  b  接受
N     F  N  否
F     F  N  是
\end{verbatim}
\end{quote}

最小 DFA 识别所有以 \texttt{a} 结尾的 \texttt{\{a,b\}} 串。

\paragraph*{（二）LL(1) 分析解析}

消除 \texttt{B} 的直接左递归：

\begin{quote}
\footnotesize
\begin{verbatim}
A  -> B C
B  -> r B'
B' -> p B' | epsilon
C  -> t | u
\end{verbatim}
\end{quote}

FIRST：

\begin{quote}
\footnotesize
\begin{verbatim}
FIRST(A)  = {r}
FIRST(B)  = {r}
FIRST(B') = {p, epsilon}
FIRST(C)  = {t, u}
\end{verbatim}
\end{quote}

FOLLOW：

\begin{quote}
\footnotesize
\begin{verbatim}
FOLLOW(A)  = {$}
FOLLOW(B)  = {t, u}
FOLLOW(B') = {t, u}
FOLLOW(C)  = {$}
\end{verbatim}
\end{quote}

预测分析表，空白处均为 error：

\begin{quote}
\footnotesize
\begin{verbatim}
       r          p              t               u           $
A      A->BC
B      B->rB'
B'                B'->pB'       B'->epsilon     B'->epsilon
C                                C->t            C->u
\end{verbatim}
\end{quote}

每个表项至多一条产生式，且 \texttt{FIRST(pB')=\{p\}} 与 \texttt{FOLLOW(B')=\{t,u\}} 不相交，所以改写后的文法是 LL(1)。

\paragraph*{（一）SLR 分析解析}

规范 LR(0) 项集族：

\begin{quote}
\footnotesize
\begin{verbatim}
I0:
S' -> . S
S  -> . C C
C  -> . c C
C  -> . d

I1:
S' -> S .

I2:
S  -> C . C
C  -> . c C
C  -> . d

I3:
C  -> c . C
C  -> . c C
C  -> . d

I4:
C  -> d .

I5:
S  -> C C .

I6:
C  -> c C .
\end{verbatim}
\end{quote}

GOTO 转移：

\begin{quote}
\footnotesize
\begin{verbatim}
GOTO(I0,S)=I1
GOTO(I0,C)=I2
GOTO(I0,c)=I3
GOTO(I0,d)=I4

GOTO(I2,C)=I5
GOTO(I2,c)=I3
GOTO(I2,d)=I4

GOTO(I3,C)=I6
GOTO(I3,c)=I3
GOTO(I3,d)=I4
\end{verbatim}
\end{quote}

FOLLOW：

\begin{quote}
\footnotesize
\begin{verbatim}
FOLLOW(S) = {$}
FOLLOW(C) = {c,d,$}
\end{verbatim}
\end{quote}

SLR 表：

\begin{quote}
\footnotesize
\begin{verbatim}
状态 | ACTION(c) | ACTION(d) | ACTION($) | GOTO(S) | GOTO(C)
0    | s3        | s4        |           | 1       | 2
1    |           |           | acc       |         |
2    | s3        | s4        |           |         | 5
3    | s3        | s4        |           |         | 6
4    | r3        | r3        | r3        |         |
5    |           |           | r1        |         |
6    | r2        | r2        | r2        |         |
\end{verbatim}
\end{quote}

表中没有多重动作，因此没有移进-规约冲突或规约-规约冲突，该文法是 SLR 文法。

\paragraph*{（二）L 属性 SDD 解析}

\begin{quote}
\footnotesize
\begin{verbatim}
D -> T L
     { L.in = T.type }

T -> int
     { T.type = int }

T -> float
     { T.type = float }

L -> id L'
     { addType(id.entry, L.in); L'.in = L.in }

L' -> , id L'1
      { addType(id.entry, L'.in); L'1.in = L'.in }

L' -> epsilon
      { }
\end{verbatim}
\end{quote}

输入 \texttt{float x, y} 的属性传递：

\begin{quote}
\footnotesize
\begin{verbatim}
T.type = float
L.in = float
addType(x, float)
L'.in = float
addType(y, float)
L'1.in = float
\end{verbatim}
\end{quote}

最终符号表：

\begin{quote}
\footnotesize
\begin{verbatim}
名字  类型
x     float
y     float
\end{verbatim}
\end{quote}

继承属性只依赖父结点或左侧兄弟结点，符合 L 属性限制。

\subsection*{三、中间代码、控制流与 SSA 解析}
\addcontentsline{toc}{subsection}{三、中间代码、控制流与 SSA 解析}


完整三地址码：

\begin{quote}
\footnotesize
\begin{verbatim}
L1: if i < n goto L2
    goto L6

L2: t1 = i * 4
    t2 = a[t1]
    if t2 > 0 goto L3
    goto L4

L3: sum = sum + t2
    goto L4

L4: i = i + 1
    goto L1

L6:
\end{verbatim}
\end{quote}

基本块与 CFG：

\begin{quote}
\footnotesize
\begin{verbatim}
B1: L1 的条件与 goto L6
B2: L2 的地址计算、数组读取和条件分支
B3: L3 的 sum 更新与 goto L4
B4: L4 的 i 更新与 goto L1
B5: L6

边：
B1->B2
B1->B5
B2->B3
B2->B4
B3->B4
B4->B1
\end{verbatim}
\end{quote}

设循环前初值为 \texttt{i0、sum0}，SSA：

\begin{quote}
\footnotesize
\begin{verbatim}
L1:
i1   = phi(i0, i2)
sum1 = phi(sum0, sum3)
if i1 < n goto L2
goto L6

L2:
t1 = i1 * 4
t2 = a[t1]
if t2 > 0 goto L3
goto L4

L3:
sum2 = sum1 + t2
goto L4

L4:
sum3 = phi(sum2, sum1)
i2 = i1 + 1
goto L1

L6:
\end{verbatim}
\end{quote}

退出 SSA 时的边复制：

\begin{quote}
\footnotesize
\begin{verbatim}
进入 L1 的循环前边：i1=i0，sum1=sum0
L4->L1 回边：i1=i2，sum1=sum3
L3->L4 边：sum3=sum2
L2->L4 的假分支边：sum3=sum1
\end{verbatim}
\end{quote}

并行复制需要在对应前驱边上执行；必要时拆分临界边。

\subsection*{四、运行时环境与目标代码生成解析}
\addcontentsline{toc}{subsection}{四、运行时环境与目标代码生成解析}


\paragraph*{（一）运行时环境解析}

\texttt{add} 的活动记录至少包含：

\begin{quote}
\footnotesize
\begin{verbatim}
参数 a、b
局部变量 t
返回值位置
返回地址
旧 BP 或控制链
保存的寄存器/机器状态
\end{verbatim}
\end{quote}

参数从右到左压栈：

\begin{quote}
\footnotesize
\begin{verbatim}
先压入 y 的值 4，作为参数 b。
再压入 x 的值 3，作为参数 a。
然后执行 call，保存返回地址并进入 add。
\end{verbatim}
\end{quote}

调用/返回：

\begin{quote}
\footnotesize
\begin{verbatim}
SP 指向当前栈顶，压栈和退栈会修改 SP。
BP 作为当前活动记录的稳定基址，用固定偏移访问参数和局部变量。
返回地址指出 add 返回后 main 中继续执行的位置。
返回值按约定放入指定寄存器或活动记录的返回值区域，再传给 z。
返回时恢复旧 BP、SP 和保存的寄存器，再跳到返回地址。
\end{verbatim}
\end{quote}

垃圾回收比较：

\begin{quote}
\footnotesize
\begin{verbatim}
引用计数在引用变化时立即维护计数，计数为 0 就可回收，暂停短；但无法回收不可达循环。
标记-清扫从根集出发标记可达对象，再清扫未标记对象，能回收不可达循环，但需要遍历堆并产生暂停。
\end{verbatim}
\end{quote}

\paragraph*{（二）目标代码生成解析}

完整目标代码：

\begin{quote}
\footnotesize
\begin{verbatim}
LD  R0, a       ; R0=a
LD  R1, b       ; R1=b
SUB R0, R1      ; R0=t1=a-b
LD  R1, c       ; R1=c
ADD R0, R1      ; R0=t2=t1+c
ST  x, R0       ; x=R0
\end{verbatim}
\end{quote}

寄存器描述符：

\begin{quote}
\footnotesize
\begin{verbatim}
初始：R0={}，R1={}
LD R0,a 后：R0={a}
LD R1,b 后：R1={b}
SUB 后：R0={t1}，R1={b}
LD R1,c 后：R0={t1}，R1={c}
ADD 后：R0={t2,x的新值}，R1={c}
ST 后：R0={x}，R1={c}
\end{verbatim}
\end{quote}

最终地址描述符：

\begin{quote}
\footnotesize
\begin{verbatim}
Addr(x)={内存位置 x, R0}
\end{verbatim}
\end{quote}

\subsection*{五、数据流分析、支配与自然循环解析}
\addcontentsline{toc}{subsection}{五、数据流分析、支配与自然循环解析}


到达定值是正向 may 分析，交汇运算为并集：

\begin{quote}
\footnotesize
\begin{verbatim}
IN[B]  = union OUT[P]，P 为 B 的前驱
OUT[B] = gen[B] union (IN[B] - kill[B])
OUT[Entry] = {}
\end{verbatim}
\end{quote}

gen/kill：

\begin{quote}
\footnotesize
\begin{verbatim}
gen[B1]={d1,d2}   kill[B1]={d4}
gen[B2]={d3}      kill[B2]={}
gen[B3]={d4}      kill[B3]={d1}
gen[B4]={}        kill[B4]={}
\end{verbatim}
\end{quote}

不动点结果：

\begin{quote}
\footnotesize
\begin{verbatim}
IN[B1]  = {}
OUT[B1] = {d1,d2}

IN[B2]  = {d1,d2,d3,d4}
OUT[B2] = {d1,d2,d3,d4}

IN[B3]  = {d1,d2,d3,d4}
OUT[B3] = {d2,d3,d4}

IN[B4]  = {d1,d2,d3,d4}
OUT[B4] = {d1,d2,d3,d4}
\end{verbatim}
\end{quote}

支配集合：

\begin{quote}
\footnotesize
\begin{verbatim}
Dom(Entry)={Entry}
Dom(B1)={Entry,B1}
Dom(B2)={Entry,B1,B2}
Dom(B3)={Entry,B1,B2,B3}
Dom(B4)={Entry,B1,B2,B4}
Dom(Exit)={Entry,B1,B2,B4,Exit}
\end{verbatim}
\end{quote}

直接支配者：

\begin{quote}
\footnotesize
\begin{verbatim}
idom(B1)=Entry
idom(B2)=B1
idom(B3)=B2
idom(B4)=B2
idom(Exit)=B4
\end{verbatim}
\end{quote}

回边与自然循环：

\begin{quote}
\footnotesize
\begin{verbatim}
B3->B2 是回边，因为 B2 支配 B3。
对应自然循环为 {B2,B3}。
\end{verbatim}
\end{quote}
