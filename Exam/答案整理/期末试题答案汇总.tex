\subsection{通用答案模板}


\subsubsection{[自动机] Thompson}


\begin{quote}
\footnotesize
\begin{verbatim}
字符 a：start --a--> end
epsilon：start --epsilon--> end
A|B：新 start epsilon 到 A/B 起点，A/B 终点 epsilon 到新 end
AB：A 终点 epsilon 到 B 起点
A*：新 start epsilon 到 A 起点和新 end，A 终点 epsilon 到 A 起点和新 end
\end{verbatim}
\end{quote}


\subsubsection{[自动机] 子集构造}


\begin{quote}
\footnotesize
\begin{verbatim}
Start = epsilon-closure({NFA start})
对每个 DFA 状态 S 和字符 a:
  T = epsilon-closure(move(S, a))
  记录 S --a--> T
含 NFA 终态的集合是 DFA 终态。
\end{verbatim}
\end{quote}


\subsubsection{[自动机] DFA 最小化}


\begin{quote}
\footnotesize
\begin{verbatim}
P0 = {终态集合, 非终态集合}
按每个输入字符的后继所在组拆分。
重复直到分组不再变化。
每个分组变成一个最小 DFA 状态。
\end{verbatim}
\end{quote}


\subsubsection{[LL]}


\begin{quote}
\footnotesize
\begin{verbatim}
1. 消除左递归。
2. 计算 FIRST。
3. 计算 FOLLOW。
4. 对 A -> alpha：
   FIRST(alpha)-{epsilon} 填 M[A,a]
   若 epsilon in FIRST(alpha)，FOLLOW(A) 填 M[A,b]
5. 表中无多重入口就是 LL(1)。
\end{verbatim}
\end{quote}


\subsubsection{[LR]}


\begin{quote}
\footnotesize
\begin{verbatim}
closure:
若 [A -> alpha . B beta, a] 在 I 中，
对 B -> gamma 和 b in FIRST(beta a)，加入 [B -> . gamma, b]。

goto(I,X):
closure({[A -> alpha X . beta, a]})

归约：
[A -> alpha ., a] 只在 action[a] 中填 reduce A -> alpha。
\end{verbatim}
\end{quote}


\subsubsection{[TAC] 回填}


\begin{quote}
\footnotesize
\begin{verbatim}
B.truelist, B.falselist, S.nextlist
makelist(i), merge(p,q), backpatch(p,L)

while:
M1 = 条件入口
翻译 B
M2 = 循环体入口
backpatch(B.truelist, M2)
翻译 S1
emit(goto M1)
S.nextlist = B.falselist
\end{verbatim}
\end{quote}


\subsubsection{[Andersen]}


\begin{quote}
\footnotesize
\begin{verbatim}
y = &x : x in pts(y)
y = x  : pts(x) subset pts(y)
*y = x : for v in pts(y), pts(x) subset pts(v)
y = *x : for v in pts(x), pts(v) subset pts(y)
\end{verbatim}
\end{quote}


\subsection{2025}


\subsubsection{题 1 [自动机] 正则表达式到 NFA、DFA、最小化}


题干要求：


\begin{quote}
\footnotesize
\begin{verbatim}
把题面正则表达式转换成 NFA。
把 NFA 转换成 DFA。
最小化 DFA。
\end{verbatim}
\end{quote}


答案写法：


\begin{quote}
\footnotesize
\begin{verbatim}
1. 按括号层次拆正则表达式。
2. 对 epsilon、字符、选择、连接、星闭包分别套 Thompson 模板。
3. 给 NFA 状态编号。
4. 写每个 DFA 状态对应的 NFA 状态集合。
5. 对每个输入字符写 move 和 epsilon-closure。
6. 含 NFA 终态的 DFA 状态标为终态。
7. 最小化时先分终态/非终态，再按转移目标组拆分。
\end{verbatim}
\end{quote}


评分点：


\begin{quote}
\footnotesize
\begin{verbatim}
NFA 结构正确。
DFA 状态集合对应关系写清。
DFA 终态判断正确。
最小化分组过程写清。
\end{verbatim}
\end{quote}


\subsubsection{题 2 [LL] 消除左递归、FIRST/FOLLOW、预测表}


题干：


\begin{quote}
\footnotesize
\begin{verbatim}
A -> B C
B -> B P | r
C -> t | u
\end{verbatim}
\end{quote}


消除左递归：


\begin{quote}
\footnotesize
\begin{verbatim}
A  -> B C
B  -> r B'
B' -> P B' | epsilon
C  -> t | u
\end{verbatim}
\end{quote}


FIRST：


\begin{quote}
\footnotesize
\begin{verbatim}
FIRST(A)  = {r}
FIRST(B)  = {r}
FIRST(B') = {P, epsilon}
FIRST(C)  = {t, u}
\end{verbatim}
\end{quote}


FOLLOW：


\begin{quote}
\footnotesize
\begin{verbatim}
FOLLOW(A)  = {$}
FOLLOW(B)  = {t, u}
FOLLOW(B') = {t, u}
FOLLOW(C)  = {$}
\end{verbatim}
\end{quote}


预测表：


\begin{quote}
\footnotesize
\begin{verbatim}
M[A,r]  = A -> B C
M[B,r]  = B -> r B'
M[B',P] = B' -> P B'
M[B',t] = B' -> epsilon
M[B',u] = B' -> epsilon
M[C,t]  = C -> t
M[C,u]  = C -> u
\end{verbatim}
\end{quote}


结论：


\begin{quote}
\footnotesize
\begin{verbatim}
表中无多重入口，消除左递归后的文法是 LL(1)。
\end{verbatim}
\end{quote}


\subsubsection{题 3 [调度] 指令调度}


目的：


\begin{quote}
\footnotesize
\begin{verbatim}
在不改变程序语义的前提下重排指令，减少流水线停顿，提高并行执行效率。
\end{verbatim}
\end{quote}


依赖定义：


\begin{quote}
\footnotesize
\begin{verbatim}
True dependence / RAW:
i 写 x，j 读 x，i 必须在 j 前。

Anti dependence / WAR:
i 读 x，j 写 x，j 不能提前破坏 i 读到的旧值。

Output dependence / WAW:
i 写 x，j 写 x，二者顺序影响最终写入值。
\end{verbatim}
\end{quote}


依赖图：


\begin{quote}
\footnotesize
\begin{verbatim}
每条指令一个节点。
RAW 用实线。
WAR 和 WAW 用虚线。
边从先执行者指向后执行者。
\end{verbatim}
\end{quote}


寄存器重命名：


\begin{quote}
\footnotesize
\begin{verbatim}
WAR 和 WAW 能通过给后写入者换新寄存器消除。
RAW 不能通过重命名消除。
\end{verbatim}
\end{quote}


调度：


\begin{quote}
\footnotesize
\begin{verbatim}
删去已通过重命名消除的 WAR/WAW。
对剩余依赖图给出拓扑序。
拓扑序就是合法调度序列。
\end{verbatim}
\end{quote}


\subsubsection{题 4 [SSA] 支配问题}


定义：


\begin{quote}
\footnotesize
\begin{verbatim}
Dom(n):
从入口到 n 的每条路径都经过的节点集合。

PostDom(n):
从 n 到出口的每条路径都经过的节点集合。

Dom Frontier(n):
n 支配某个前驱，但不严格支配该节点的节点集合。
\end{verbatim}
\end{quote}


支配关系图是森林：


\begin{quote}
\footnotesize
\begin{verbatim}
除入口外，每个节点有唯一直接支配者 idom。
idom 严格支配该节点。
严格支配关系无环。
因此每个节点至多一个父节点且无环，构成树；多入口时构成森林。
\end{verbatim}
\end{quote}


构建支配关系图：


\begin{quote}
\footnotesize
\begin{verbatim}
1. 对每个节点求 Dom 集。
2. 在 Dom(n)-{n} 中找最靠近 n 的节点作为 idom(n)。
3. 画 idom(n) -> n。
\end{verbatim}
\end{quote}


\subsubsection{题 5 [符号执行] 敏感性、CNF、Tseitin}


敏感性：


\begin{quote}
\footnotesize
\begin{verbatim}
Path-sensitive：区分不同控制流路径。
Flow-sensitive：区分程序点和语句顺序。
Context-sensitive：区分函数调用上下文。
\end{verbatim}
\end{quote}


CNF：


\begin{quote}
\footnotesize
\begin{verbatim}
CNF 是子句的合取，每个子句是文字的析取。
(a or not b) and (c or d or not e)
\end{verbatim}
\end{quote}


Tseitin：


\begin{quote}
\footnotesize
\begin{verbatim}
1. 给每个子表达式引入新变量。
2. 写新变量与子表达式等价的 CNF 约束。
3. 加入根变量为真的子句。
4. 得到与原公式同时可满足的 CNF。
\end{verbatim}
\end{quote}


同时可满足证明：


\begin{quote}
\footnotesize
\begin{verbatim}
F1 = (a0 or ... or an or c) and (b0 or ... or bm or not c)
F2 = (a0 or ... or an or b0 or ... or bm)

F1 -> F2：
若 c=false，则第一子句要求某个 ai=true。
若 c=true，则第二子句要求某个 bj=true。
因此 F2=true。

F2 -> F1：
若某个 ai=true，令 c=true。
若某个 bj=true，令 c=false。
因此 F1=true。

所以 F1 与 F2 同时可满足。
\end{verbatim}
\end{quote}


\subsubsection{题 6 [Andersen] 指针别名}


题干结构：


\begin{quote}
\footnotesize
\begin{verbatim}
p = &a;
q = &b;
*p = q;
r = &c;
s = p;
t = *p;
*s = r;
\end{verbatim}
\end{quote}


约束：


\begin{quote}
\footnotesize
\begin{verbatim}
a in pts(p)
b in pts(q)
for v in pts(p), pts(q) subset pts(v)
c in pts(r)
pts(p) subset pts(s)
for v in pts(p), pts(v) subset pts(t)
for v in pts(s), pts(r) subset pts(v)
\end{verbatim}
\end{quote}


闭包：


\begin{quote}
\footnotesize
\begin{verbatim}
pts(p) = {a}
pts(q) = {b}
由 *p=q 得 pts(a) 包含 {b}
pts(r) = {c}
由 s=p 得 pts(s) 包含 {a}
由 t=*p 得 pts(t) 包含 pts(a)，先得到 {b}
由 *s=r 得 pts(a) 包含 {c}
pts(a) = {b,c}
pts(t) = {b,c}
\end{verbatim}
\end{quote}

\subsubsection{题 1 [自动机] \texttt{a ( () | [] )*}}


答案写法：


\begin{quote}
\footnotesize
\begin{verbatim}
1. `a` 画一条字符边。
2. `()` 与 `[]` 分别看作两个后缀 token 序列。
3. `(() | [])` 用选择模板。
4. 外层 `*` 用闭包模板。
5. 最后与前面的 `a` 连接。

\end{verbatim}
\end{quote}


\subsubsection{题 2 [LL] C 声明文法}


题干：


\begin{quote}
\footnotesize
\begin{verbatim}
D -> D()
D -> D[]
D -> *D
D -> (D)
D -> id
\end{verbatim}
\end{quote}


FIRST：


\begin{quote}
\footnotesize
\begin{verbatim}
FIRST(D) = {*, (, id}
\end{verbatim}
\end{quote}


FOLLOW：


\begin{quote}
\footnotesize
\begin{verbatim}
FOLLOW(D) = {(, [, ), $}
\end{verbatim}
\end{quote}


结论：


\begin{quote}
\footnotesize
\begin{verbatim}
原文法有直接左递归 D -> D() 和 D -> D[]。
预测分析表会在同一入口填入多条产生式。
因此原文法不是 LL(1)。
\end{verbatim}
\end{quote}


\subsubsection{题 3 [LR] C 声明文法}


答题模板：


\begin{quote}
\footnotesize
\begin{verbatim}
1. 写增广文法 D' -> D。
2. 从 [D' -> . D, $] 开始做 closure。
3. 对每个终结符和非终结符做 goto。
4. shift 项按 goto 填 action。
5. reduce 项按 FOLLOW 或 LR(1) 向前看符号填 action。
6. 若同一 action 表格有 shift/reduce 或 reduce/reduce，则说明冲突。
\end{verbatim}
\end{quote}


SLR 冲突解释：


\begin{quote}
\footnotesize
\begin{verbatim}
SLR 使用 FOLLOW(D) 放置归约。
D 后面既能接后缀 ()、[]，也能结束或遇到右括号。
FOLLOW 过粗，会把归约放到产生冲突的位置。
\end{verbatim}
\end{quote}


消解方式：


\begin{quote}
\footnotesize
\begin{verbatim}
后缀 () 与 [] 优先级高于前缀 *。
遇到 () 或 [] 时移入，先形成后缀结构。
遇到 $ 或 ) 时再归约。
\end{verbatim}
\end{quote}


\subsubsection{题 4 [ANTLR] C 声明优先级上升}


核心优先级：


\begin{quote}
\footnotesize
\begin{verbatim}
postfix () 和 [] 优先级高。
prefix * 优先级低于 postfix。
括号 (D) 改变结合结构。
id 是基本项。
\end{verbatim}
\end{quote}


输入：


\begin{quote}
\footnotesize
\begin{verbatim}
(*(*a)())[]
\end{verbatim}
\end{quote}


解释写法：


\begin{quote}
\footnotesize
\begin{verbatim}
1. 最内层 a 是基本项。
2. (*a) 通过括号把 pointer 结构绑定成一个整体。
3. (*a)() 先应用 postfix function-call。
4. *(*a)() 形成 pointer to function-returning 结构。
5. 外层括号后再接 []，形成 array 后缀。
\end{verbatim}
\end{quote}


\subsubsection{题 5 [SDD] C 声明英文说明}


属性：


\begin{quote}
\footnotesize

D.name：综合属性，标识符名。
D.desc：综合属性，英文说明片段。
\end{verbatim}
\end{quote}


规则：


\begin{quote}
\footnotesize
\begin{verbatim}
D -> id       D.name = id.lexeme; D.desc = ""

D -> * D1     D.name = D1.name; D.desc = D1.desc + " pointer to"
D -> ( D1 )   D.name = D1.name; D.desc = D1.desc
\end{verbatim}
\end{quote}


输出：


\begin{quote}
\footnotesize
\begin{verbatim}
declare D.name as D.desc
\end{verbatim}
\end{quote}

\subsubsection{题 5 [SDD] 声明个数与嵌套深度}


题干：


\begin{quote}
\footnotesize
\begin{verbatim}
P -> D
D -> D ; D
D -> T id
D -> func id {D}
T -> int
\end{verbatim}
\end{quote}


统计声明个数：


\begin{quote}
\footnotesize
\begin{verbatim}
P -> D              P.count = D.count
D -> D1 ; D2        D.count = D1.count + D2.count
D -> T id           D.count = 1
D -> func id {D1}   D.count = 1 + D1.count

\begin{quote}

P -> D              D.depth = 0

D -> T id           print(id, D.depth)
D -> func id {D1}   D1.depth = D.depth + 1
T -> int            无需规则
\end{verbatim}
\end{quote}


\subsubsection{题 6 [TAC] GCD while 回填}


题干：


\begin{quote}
\footnotesize
\begin{verbatim}
while a != b do
  if a > b then
    a = a - b
  else
    b = b - a
\end{verbatim}
\end{quote}


中间代码：


\begin{quote}
\footnotesize
\begin{verbatim}
100: if a != b goto 102
101: goto 108
102: if a > b goto 104
103: goto 106
104: a = a - b
105: goto 100
106: b = b - a
107: goto 100
108: ...
\end{verbatim}
\end{quote}


回填说明：


\begin{quote}
\footnotesize
\begin{verbatim}
while 条件真链回填到 102。
while 条件假链回填到 108。
if 条件真链回填到 104。

两个分支结束后跳回 100。
\end{verbatim}
\end{quote}

\subsubsection{题 1 [自动机] \texttt{epsilon | (a* b)}}


答案写法：


\begin{quote}

\begin{verbatim}
1. epsilon 与 a* b 做选择。

5. 再做子集构造和最小化。

\subsubsection{题 2 [LL] \texttt{S -> AB, A -> Aaa | a, B -> Bbb | b}}


消除左递归：


\begin{quote}
\footnotesize
\begin{verbatim}
S  -> A B
A  -> a A'
A' -> a a A' | epsilon
B  -> b B'
B' -> b b B' | epsilon
\end{verbatim}
\end{quote}


FIRST：


\begin{quote}
\footnotesize
\begin{verbatim}
FIRST(S)  = {a}
FIRST(A)  = {a}
FIRST(A') = {a, epsilon}
FIRST(B)  = {b}
FIRST(B') = {b, epsilon}
\end{verbatim}
\end{quote}


FOLLOW：


\begin{quote}
\footnotesize
\begin{verbatim}
FOLLOW(S)  = {$}
FOLLOW(A)  = {b}
FOLLOW(A') = {b}
FOLLOW(B)  = {$}
FOLLOW(B') = {$}
\end{verbatim}
\end{quote}


预测表核心项：


\begin{quote}
\footnotesize
\begin{verbatim}
M[S,a]  = S -> A B
M[A,a]  = A -> a A'
M[A',a] = A' -> a a A'
M[A',b] = A' -> epsilon
M[B,b]  = B -> b B'
M[B',b] = B' -> b b B'
M[B',$] = B' -> epsilon
\end{verbatim}
\end{quote}


结论：


\begin{quote}
\footnotesize
\begin{verbatim}
表中无多重入口，G' 是 LL(1)。
\end{verbatim}
\end{quote}


\subsubsection{题 3 [LR] \texttt{S -> V=E | E, E -> V, V -> x | *E}}


答案模板：


\begin{quote}
\footnotesize
\begin{verbatim}
1. 写 FIRST/FOLLOW。
2. 构造 LR(1) 项目集。
3. 对 [A -> alpha ., a] 按 a 设置归约。
4. 给出 LR(1) 表并检查冲突。
5. 对输入 *x=**x 按状态栈、符号栈、输入串写移入/归约过程。
6. LALR(1) 合并同心项目集后检查冲突。
\end{verbatim}
\end{quote}


\subsubsection{题 4 [SDD] 逗号与嵌套输出}


答案模板：


\begin{quote}
\footnotesize
\begin{verbatim}
定义综合属性 L.list，保存从左到右收集到的 a 的编号。
定义继承属性 L.base，表示当前嵌套或当前位置基准。
每遇到一个 a，就把当前编号加入输出。
遇到嵌套结构时，把基准传入内部子树。

\subsubsection{题 5 [TAC] do-while 回填}


模板：


\begin{quote}
\footnotesize
\begin{verbatim}
do S while B

M1 = 循环体入口
翻译 S
M2 = 条件入口
backpatch(S.nextlist, M2)
翻译 B
backpatch(B.truelist, M1)
S.nextlist = B.falselist
\end{verbatim}
\end{quote}


\subsubsection{题 6 [CFG] Chomsky Normal Form}


CNF 要求：


\begin{quote}
\footnotesize
\begin{verbatim}
S -> epsilon 只允许开始符号产生空串。
A -> B C，其中 B、C 是非终结符。
A -> a，其中 a 是终结符。
\end{verbatim}
\end{quote}


改写步骤：


\begin{quote}
\footnotesize
\begin{verbatim}
1. 新增开始符号 S0 -> S。
2. 删除 epsilon 产生式。
3. 删除单产生式 A -> B。
4. 删除无用符号。
5. 长右部拆成二元产生式。
6. 混合右部中的终结符替换成新非终结符。
\end{verbatim}
\end{quote}

\begin{quote}

\begin{quote}

4. 函数调用填参数传递、call、返回值接收。

\end{verbatim}
\end{quote}
