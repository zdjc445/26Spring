# 编译原理期末突击资料

本目录按 `Slides/Slides/handout` 与三份 Recap PPT 的新老师授课主线整理，全部资料已生成 `md`、`tex`、`pdf` 三种版本。

使用顺序：

1. 先读 `00-2025风格零基础期末总复习资料.pdf`。
2. 再做 `模拟卷/` 下 8 套模拟卷，每套先做 A 卷题目，再对照 B 详解。
3. 若复习范围只到 `期末复习/` 下四份复习 PDF，先做 `模拟卷/期末复习PPT专项模拟卷合集-题目与详解.pdf`。
4. 错题回到 `编译原理课程整理/` 中对应分卷补细节。

模拟卷主线：词法分析、LL、IR/SSA、数据流分析、符号执行、过程间分析、Andersen 指针分析、目标代码、寄存器分配、指令调度。
