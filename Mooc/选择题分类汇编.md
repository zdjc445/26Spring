**20. 单选(2分)**
  在UNIX系统中运行以下程序，最多可再产生出______进程?
  
  main( ){
     fork( ); /*←pc(程序计数器)，进程A
     fork( );
     fork( );
}
  
A. 9；
B. 7；
C. 5；
D. 3；

**解答：** B
**简要说明：** 每次fork()调用都会使当前进程复制出一个子进程。
初始1个进程（A）。
第一次fork()：A产生B。此时有A, B共2个进程。
第二次fork()：A产生C，B产生D。此时有A, B, C, D共4个进程。
第三次fork()：A产生E，B产生F，C产生G，D产生H。此时有A, B, C, D, E, F, G, H共8个进程。
题目问“最多可**再**产生出”多少个进程，即除了初始进程A之外，一共产生了 $2^3 - 1 = 7$ 个子进程。

**19. 单选(2分)**
  假定某页式管理系统中，主存128KB，分成32块，块号为0，1，2，3，...，31；某作业有5块，其页号为0，1，2，3，4，被分别装入主存的3，8，4，6，9块中。有一逻辑地址为[3，70]。试求出相应的物理地址_______（其中方括号中的第一个元素为页号，第二个元素为页内地址，按十进制计算）。
  
  
A. 24576
B. 14646
C. 34576
D. 24646

**解答：** D
**简要说明：**
1.  **计算块大小（页大小）：**
    主存总容量 = 128 KB
    主存块数 = 32 块
    每块大小 = 128 KB / 32 = 4 KB。
    页内地址 70，表示在页内的偏移量。
2.  **查找页表：**
    逻辑地址的页号为 3。
    根据题目，页号 3 对应的物理块号是 6。
3.  **计算物理地址：**
    物理地址 = 物理块号 × 每块大小 + 页内地址
    物理地址 = 6 × 4 KB + 70 B
    物理地址 = 24 KB + 70 B
    换算成字节：24 KB = 24 * 1024 B = 24576 B
    物理地址 = 24576 B + 70 B = 24646 B。
