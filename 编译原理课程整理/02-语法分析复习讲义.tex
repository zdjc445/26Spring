\subsection{一、考试目标}


语法分析题分三类：


\begin{quote}
\footnotesize
\begin{verbatim}
LL(1)：消除左递归 -> FIRST -> FOLLOW -> 预测分析表 -> 判断
LR：项目 -> closure -> goto -> 分析表 -> 冲突
ANTLR：看优先级、结合性、语法树
\end{verbatim}
\end{quote}


零基础优先级：


\begin{quote}
\footnotesize
\begin{verbatim}
先把 LL(1) 做熟，再背 LR 模板，最后看 ANTLR 优先级。
\end{verbatim}
\end{quote}


\subsection{二、CFG 基本概念}


上下文无关文法：


\begin{quote}
\footnotesize
\begin{verbatim}
G = (N, T, S, P)
N : 非终结符
T : 终结符
S : 开始符号
P : 产生式集合
\end{verbatim}
\end{quote}


语言：


\begin{quote}
\footnotesize
\begin{verbatim}
L(G) = {w in T* | S =>* w}
\end{verbatim}
\end{quote}


派生：


\begin{quote}
\footnotesize
\begin{verbatim}
最左派生：每次展开最左非终结符
最右派生：每次展开最右非终结符
\end{verbatim}
\end{quote}


二义性：


\begin{quote}
\footnotesize
\begin{verbatim}
同一个终结符串有两棵不同语法树，则文法有二义性。
\end{verbatim}
\end{quote}


典型例子：


\begin{quote}
\footnotesize
\begin{verbatim}
E -> E + E | E * E | id
\end{verbatim}
\end{quote}


消除优先级和结合性后：


\begin{quote}
\footnotesize
\begin{verbatim}
E -> E + T | T
T -> T * F | F
F -> id | (E)
\end{verbatim}
\end{quote}


\subsection{三、左递归消除}


直接左递归：


\begin{quote}
\footnotesize
\begin{verbatim}
A -> A alpha1 | A alpha2 | beta1 | beta2
\end{verbatim}
\end{quote}


改写：


\begin{quote}
\footnotesize
\begin{verbatim}
A  -> beta1 A' | beta2 A'
A' -> alpha1 A' | alpha2 A' | epsilon
\end{verbatim}
\end{quote}


例：


\begin{quote}
\footnotesize
\begin{verbatim}
L -> L , id | id
\end{verbatim}
\end{quote}


消除后：


\begin{quote}
\footnotesize
\begin{verbatim}
L  -> id L'
L' -> , id L' | epsilon
\end{verbatim}
\end{quote}


\subsection{四、FIRST 集}


含义：


\begin{quote}
\footnotesize
\begin{verbatim}
FIRST(alpha) = alpha 能推导出的串的第一个终结符集合。
若 alpha 能推出空串，则 epsilon in FIRST(alpha)。
\end{verbatim}
\end{quote}


计算规则：


\begin{quote}
\footnotesize
\begin{verbatim}
FIRST(终结符 a) = {a}
FIRST(epsilon) = {epsilon}
FIRST(A) 看 A 的各个产生式右部
FIRST(XY) 先看 FIRST(X)，若 X 能推出 epsilon，再看 FIRST(Y)
\end{verbatim}
\end{quote}


\subsection{五、FOLLOW 集}


含义：


\begin{quote}
\footnotesize
\begin{verbatim}
FOLLOW(A) = 在某个句型中能紧跟在 A 后面的终结符集合。
开始符号的 FOLLOW 集含 $。
\end{verbatim}
\end{quote}


计算规则：


\begin{quote}
\footnotesize
\begin{verbatim}
若 S 是开始符号，$ in FOLLOW(S)。
若有 A -> alpha B beta，则 FIRST(beta)-{epsilon} 加入 FOLLOW(B)。
若有 A -> alpha B，或 beta 能推出 epsilon，则 FOLLOW(A) 加入 FOLLOW(B)。
\end{verbatim}
\end{quote}


\subsection{六、预测分析表}


对每条产生式 \texttt{A -> alpha}：


\begin{quote}
\footnotesize
\begin{verbatim}
1. 对 FIRST(alpha)-{epsilon} 中每个终结符 a：
   M[A,a] = A -> alpha

2. 若 epsilon in FIRST(alpha)：
   对 FOLLOW(A) 中每个终结符 b：
   M[A,b] = A -> alpha
\end{verbatim}
\end{quote}


判断：


\begin{quote}
\footnotesize
\begin{verbatim}
每个表格最多一条产生式，则是 LL(1)。
某个表格出现两条产生式，则不是 LL(1)。
\end{verbatim}
\end{quote}


\subsection{七、LL 真题最小例子}


题面：


\begin{quote}
\footnotesize
\begin{verbatim}
D -> T L
T -> int | real
L -> L , id | id
\end{verbatim}
\end{quote}


消除左递归：


\begin{quote}
\footnotesize
\begin{verbatim}
D  -> T L
T  -> int | real
L  -> id L'
L' -> , id L' | epsilon
\end{verbatim}
\end{quote}


FIRST：


\begin{quote}
\footnotesize
\begin{verbatim}
FIRST(D)  = {int, real}
FIRST(T)  = {int, real}
FIRST(L)  = {id}
FIRST(L') = {comma, epsilon}
\end{verbatim}
\end{quote}


FOLLOW：


\begin{quote}
\footnotesize
\begin{verbatim}
FOLLOW(D)  = {$}
FOLLOW(T)  = {id}
FOLLOW(L)  = {$}
FOLLOW(L') = {$}
\end{verbatim}
\end{quote}


预测表：


\begin{quote}
\footnotesize
\begin{verbatim}
M[D,int]  = D -> T L
M[D,real] = D -> T L
M[T,int]  = T -> int
M[T,real] = T -> real
M[L,id]   = L -> id L'
M[L',comma] = L' -> , id L'
M[L',$]   = L' -> epsilon
\end{verbatim}
\end{quote}


结论：


\begin{quote}
\footnotesize
\begin{verbatim}
表中无多重入口，是 LL(1)。
\end{verbatim}
\end{quote}


\subsection{八、LR 项目与 closure}


LR 项目是在产生式右部加一个点：


\begin{quote}
\footnotesize
\begin{verbatim}
A -> alpha . beta
\end{verbatim}
\end{quote}


含义：


\begin{quote}
\footnotesize
\begin{verbatim}
点左边已经识别，点右边还未识别。
\end{verbatim}
\end{quote}


LR(1) 项目带向前看符号：


\begin{quote}
\footnotesize
\begin{verbatim}
[A -> alpha . beta, a]
\end{verbatim}
\end{quote}


closure 模板：


\begin{quote}
\footnotesize
\begin{verbatim}
若 [A -> alpha . B beta, a] 在 I 中，
对每条 B -> gamma，
对每个 b in FIRST(beta a)，
加入 [B -> . gamma, b]。
\end{verbatim}
\end{quote}


goto 模板：


\begin{quote}
\footnotesize
\begin{verbatim}
goto(I, X) =
closure({[A -> alpha X . beta, a] | [A -> alpha . X beta, a] in I})
\end{verbatim}
\end{quote}


\subsection{九、LR 分析表}


写表规则：


\begin{quote}
\footnotesize
\begin{verbatim}
若 goto(Ii, a) = Ij，a 是终结符：
  action[i,a] = shift j

若 [A -> alpha ., a] 在 Ii：
  action[i,a] = reduce A -> alpha

若 [S' -> S ., $] 在 Ii：
  action[i,$] = accept

若 goto(Ii, A) = Ij，A 是非终结符：
  goto[i,A] = j
\end{verbatim}
\end{quote}


冲突：


\begin{quote}
\footnotesize
\begin{verbatim}
shift/reduce：同一格既要移入又要归约。
reduce/reduce：同一格有两个归约。
\end{verbatim}
\end{quote}


SLR 与 LR(1) 区别：


\begin{quote}
\footnotesize
\begin{verbatim}
SLR 归约看 FOLLOW(A)。
LR(1) 归约只看项目里的向前看符号 a。
LR(1) 更精细，冲突更少。
\end{verbatim}
\end{quote}


\subsection{十、ANTLR4 优先级上升}


ANTLR4 对直接左递归表达式按优先级改写。记题时抓三点：


\begin{quote}
\footnotesize
\begin{verbatim}
1. 写出运算符优先级。
2. 写出结合性。
3. 按优先级和结合性给语法树。
\end{verbatim}
\end{quote}


例：


\begin{quote}
\footnotesize
\begin{verbatim}
E -> E ! | E ^ E | E + E | INT
\end{verbatim}
\end{quote}


题面说明：


\begin{quote}
\footnotesize
\begin{verbatim}
! 最高，后缀
^ 右结合
+ 最低，左结合
\end{verbatim}
\end{quote}


输入：


\begin{quote}
\footnotesize
\begin{verbatim}
1 + 2 ^ 3 ^ 4 + 5 ! !
\end{verbatim}
\end{quote}


答案结构：


\begin{quote}
\footnotesize
\begin{verbatim}
(1 + (2 ^ (3 ^ 4))) + ((5!)!)
\end{verbatim}
\end{quote}


\subsection{十一、CFL 与 NPDA}


要背：


\begin{quote}
\footnotesize
\begin{verbatim}
CFG 与 NPDA 定义同一类语言：上下文无关语言。
CFL 对并、连接、Kleene star、反转封闭。
CFL 对交、补、差不封闭。
\end{verbatim}
\end{quote}


CFL 泵引理用于证明语言不是 CFL：


\begin{quote}
\footnotesize
\begin{verbatim}
s = uvwxy
vx != epsilon
|vwx| <= C
对任意 i >= 0，u v^i w x^i y in L
\end{verbatim}
\end{quote}


\subsection{十二、自测题}


题 1：为什么左递归会影响递归下降分析？


答案：


\begin{quote}
\footnotesize
\begin{verbatim}
递归下降中 A 调用 A，会无限递归。
\end{verbatim}
\end{quote}


题 2：\texttt{A -> A a | b} 消除左递归。


答案：


\begin{quote}
\footnotesize
\begin{verbatim}
A  -> b A'
A' -> a A' | epsilon
\end{verbatim}
\end{quote}


题 3：LL(1) 判断看什么？


答案：


\begin{quote}
\footnotesize
\begin{verbatim}
看预测分析表是否有多重入口。
\end{verbatim}
\end{quote}


题 4：LR(1) 归约条件怎么写？


答案：


\begin{quote}
\footnotesize
\begin{verbatim}
若状态 Ii 中有 [A -> alpha ., a]，则只在 action[i,a] 填 reduce A -> alpha。
\end{verbatim}
\end{quote}
