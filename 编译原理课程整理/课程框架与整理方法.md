# 编译原理复习讲义整理方法与课程框架

## 本分支沿用的整理方法

1. 先读资料结构：`Slides/Slides` 提供课堂主线，`Review/compile.pdf` 提供压缩知识点，`Exam` 提供真题题型。
2. 按考试链路分卷：词法分析、语法分析、语义与 IR、代码生成与优化、程序分析。
3. 每卷同时包含三类内容：知识点、答题步骤、自测题答案。
4. Exam 单独整理：同类题归并，题目旁标注重复题型，答案写成可直接套用的步骤。
5. Markdown 作为内容源，LaTeX 生成 PDF，保留 `.md/.tex/.pdf` 三类文件。
6. 编译后只保留源文件和 PDF，清理 `.aux/.log/.out/.toc` 等中间文件。

## 文件导航

- `01-编译器概览与词法分析复习讲义.md/.tex/.pdf`：编译器结构、正则表达式、DFA、NFA、子集构造、DFA 最小化。
- `02-语法分析复习讲义.md/.tex/.pdf`：CFG、FIRST/FOLLOW、LL(1)、LR(0)/SLR/LR(1)、ANTLR 优先级上升。
- `03-语义分析与中间代码复习讲义.md/.tex/.pdf`：语法制导定义、属性文法、回填、三地址码、SSA、支配关系。
- `04-代码生成与优化复习讲义.md/.tex/.pdf`：目标代码生成、寻址模式、局部优化、寄存器分配、指令调度。
- `05-程序分析与符号执行复习讲义.md/.tex/.pdf`：数据流分析、符号执行、SAT/CNF/Tseitin、指针分析、Datalog。
- `Exam/答案整理/期末试题答案汇总.md/.tex/.pdf`：2020、2021、2022、2023、2025 题型与答案模板。

## 考前使用顺序

1. 先读 `课程框架与整理方法.pdf`，明确课程分层和考试题型。
2. 再读 `01` 和 `02`，这些是选择题、构造题、自动机和语法分析的基础。
3. 接着读 `03`，重点掌握语法制导翻译、回填、SSA 和支配关系。
4. 再读 `04` 和 `05`，对应 2025 的指令调度、符号执行和指针别名。
5. 最后做 `Exam/答案整理/期末试题答案汇总.pdf`，用题型模板检查遗漏。
