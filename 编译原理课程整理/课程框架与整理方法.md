# 编译原理零基础突击路线图

## 目标

这套讲义按“期末能写出步骤分”整理。每一章只保留四类内容：

- 必背定义：题目要求“解释、说明、定义”时直接写。
- 固定算法：自动机、LL、LR、回填、SSA、数据流、Andersen。
- 最小例子：看懂题型，不展开长推导。
- 真题答法：按题目要求列步骤、写表、写结论。

阅读顺序：

```text
01 词法分析 -> 02 语法分析 -> 03 语义与中间代码
-> 04 后端 -> 05 程序分析 -> Exam/答案整理
```

## 分数优先级

第一优先级，先会做题：

- 正则表达式、Thompson NFA、子集构造 DFA、DFA 最小化。
- 消除左递归、FIRST、FOLLOW、预测分析表、LL(1) 判断。
- 语法制导定义、三地址码、布尔表达式回填。
- 指令调度三类依赖、寄存器重命名、列表调度。
- 支配、支配边界、SSA 中 phi 的放置位置。
- 符号执行、CNF、Tseitin、Andersen 指针分析。

第二优先级，掌握模板：

- LR(0)、SLR(1)、LR(1) 的项目、closure、goto、分析表。
- ANTLR4 左递归表达式改写与优先级上升。
- 寄存器分配、SSA 转出、基本数据流分析。

第三优先级，背定义拿小分：

- 编译器阶段划分。
- CFG、NPDA、CFL 封闭性。
- flow-sensitive、path-sensitive、context-sensitive、field-sensitive。

## 答题格式

自动机题：

```text
1. 按正则结构分层。
2. 套 Thompson 模板画 NFA。
3. 写 epsilon-closure 和 move。
4. 列 DFA 状态集合表。
5. 标终态。
6. 按终态/非终态初分组，迭代拆分完成最小化。
```

LL 题：

```text
1. 消除左递归。
2. 写 FIRST。
3. 写 FOLLOW。
4. 填预测分析表。
5. 表中无多重入口就是 LL(1)，有多重入口就不是。
```

中间代码题：

```text
1. 写 truelist、falselist、nextlist。
2. 为条件跳转留空目标。
3. 用 backpatch 填循环入口、循环体入口、循环出口。
4. 最后写出带编号的三地址码。
```

分析题：

```text
先写定义，再写构造规则，最后写结论。
```
