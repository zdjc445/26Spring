第 2 问示范：接口声明

下面是“接口声明”的写法示范。考试时方法名、参数和返回值要按题干给出的字段调整；这里重点展示接口放在哪个包、层间依赖怎么写。

展示层与逻辑层交互接口

package com.payroll.service;

import com.payroll.dto.SocialInsuranceEntryRequest;
import com.payroll.dto.SocialInsuranceEntryView;
import com.payroll.dto.SubmitResult;

public interface SocialInsuranceService {
    SocialInsuranceEntryView loadEntryPage(String employeeId);

    SubmitResult submitSocialInsurance(
        SocialInsuranceEntryRequest request
    );
}

逻辑层与数据层交互接口

package com.payroll.repository;

import com.payroll.entity.SocialInsuranceRecord;

public interface SocialInsuranceRepository {
    SocialInsuranceRecord findByEmployeeId(String employeeId);

    void save(SocialInsuranceRecord record);

}

页面控制器调用 Service

package com.payroll.web.controller;

import com.payroll.dto.SocialInsuranceEntryRequest;
import com.payroll.dto.SubmitResult;
import com.payroll.service.SocialInsuranceService;

public class SocialInsuranceController {
    private final SocialInsuranceService service;

    public SocialInsuranceController(
        SocialInsuranceService service
    ) {
        this.service = service;
    }

    public SubmitResult submit(
        SocialInsuranceEntryRequest request
    ) {
        return service.submitSocialInsurance(request);
    }
}

Service 涉及员工数据时的数据接口

package com.payroll.repository;

import com.payroll.entity.Employee;

public interface EmployeeRepository {
    Employee findById(String employeeId);
}

答题检查点

1. 图里有客户端和服务器端。
2. 浏览器端写了 HTML、CSS、JS。
3. 网络通信写了 HTTP / REST API。
4. 后端有展示层、逻辑层、数据层。
5. 题干所有功能模块都放进对应层。
6. 接口写了所属包名。
7. 接口只写声明，不写实现。
8. 方法围绕“社会保险录入”业务。
9. 依赖方向是 Controller -> Service -> Repository。
